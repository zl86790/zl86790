## 🛠️ Featured Project

### LizorCube Pilot

An AI-powered coding assistant built as a VS Code extension.

Designed to bring agentic AI capabilities into real-world software engineering workflows.

**Key Features**

- Multi-agent collaboration and task orchestration.
- DAG-based task planning and execution.
- Multi-model support.
- Code analysis, generation, and cross-language migration.
- Automated testing, validation, and debugging.
- Human-in-the-loop approval workflows.
- Integrated CLI and multi-session management.

Built with TypeScript, focusing on practical AI-assisted software development.
