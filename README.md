## 🛠️ Featured Project

### LizorCube Pilot

**An AI-powered coding assistant built as a VS Code extension.**

Designed to bring agentic AI capabilities into real-world software engineering workflows.

Unlike a simple code completion tool, LizorCube Pilot focuses on multi-step engineering tasks, agent collaboration, and automated code validation.

### Key Features

- **Multi-Agent Architecture** — Specialized agents collaborate on complex engineering tasks.
- **DAG-Based Planning** — Visual task decomposition, dependencies, and execution orchestration.
- **Multi-Model Support** — Integration with multiple LLM providers and intelligent model routing.
- **Code Engineering** — Code analysis, generation, refactoring, and cross-language migration.
- **Automated Validation** — Linting, building, testing, and debugging workflows.
- **Human-in-the-Loop** — Approval workflows for file modifications and shell operations.
- **Session Management** — Multi-session support, task history, and integrated CLI.

Built with TypeScript, focusing on practical AI-assisted software development.
